# 💊 PharmacyBy — Design de Produto (UI/UX)

> Projeto acadêmico de **UI/UX Design** desenvolvido no 1° período do curso de Ciência da Computação na UNINASSAU.  
> O PharmacyBy é um conceito de aplicativo de farmácia focado na experiência do usuário — da pesquisa inicial ao protótipo navegável.

---

## 📋 Sobre o Projeto

O **PharmacyBy** é um projeto de design de produto desenvolvido em grupo, com o objetivo de aplicar na prática os fundamentos de UX Research, arquitetura de informação e prototipação de interfaces.

O projeto passou pelas etapas:

- 📌 Definição do problema e requisitos (PRD)
- 🗺️ Estruturação da experiência do usuário (UX)
- 🎨 Prototipação de telas no Figma
- 📋 Organização e gestão via Trello

> ⚠️ **Projeto em desenvolvimento** — algumas entregas ainda estão em andamento.
